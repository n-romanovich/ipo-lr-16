# Лабораторная работа N 16-22

## Pirate PUZZLES - магазин головоломок на любой вкус и возраст

## Суть проекта - маназин, в котором можно купить игрушки-головоломки


Доступные страницы:
- http://127.0.0.1:8000/  Домашняя страница магазина
- http://127.0.0.1:8000/catalog/  Каталог товаров с фильтрацией и поиском
- http://127.0.0.1:8000/catalog/1/  Детальная информация о товаре
- http://127.0.0.1:8000/cart/  Корзина пользователя
- http://127.0.0.1:8000/about  Страница, на которой можно узнать информацию о проекте, перейдя на другие ссылки
- http://127.0.0.1:8000/about_shop  Страница с информацией о лабораторной работе
- http://127.0.0.1:8000/about_us  Страница с информацией о авторе работы
- http://127.0.0.1:8000/checkout/  Оформление заказа
- http://127.0.0.1:8000/checkout/success/  Страница успешного заказа
- http://127.0.0.1:8000/signup/  Регистрация
- http://127.0.0.1:8000/profile/  Личный кабинет
- http://127.0.0.1:8000/settings/  Смена пароля

API endpoints:
- GET/POST http://127.0.0.1:8000/api/products/  Список/создание товаров (GET — всем, остальное — только админу)
- GET/PUT/DELETE http://127.0.0.1:8000/api/products/1/  Детально/изменить/удалить товар
- GET/POST http://127.0.0.1:8000/api/categories/  Список/создание категорий
- GET/POST http://127.0.0.1:8000/api/manufacturers/  Список/создание производителей
- GET/POST http://127.0.0.1:8000/api/carts/  Список/создание корзин
- GET/POST http://127.0.0.1:8000/api/cart-items/  Список/создание элементов корзины
- GET/PATCH http://127.0.0.1:8000/api/me/  Профиль текущего пользователя
- GET http://127.0.0.1:8000/api/orders/  Заказы (свои — у пользователя, все — у админа)
